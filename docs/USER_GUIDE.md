# MinisCanvas 使用手册

MinisCanvas 是一款 macOS 原生的 AI 对话与智能体应用。你在对话里提出要求，模型可以读写你授权的文件夹、运行命令、浏览网页，而每一步有风险的动作都会先问你。

本手册对应应用版本 0.1.0。

关于画布：应用里的画布功能目前冻结，本手册不介绍画布。

## 快速开始

### 一、系统要求

- macOS 14.0 或更新版本。
- 安装包同时包含 Apple 芯片和 Intel 两种架构，不需要装 Rosetta（Intel 机器上的实际运行尚未实机验证，见“已知限制”）。
- 应用本身不带模型。你需要自己准备一个模型服务商的账号和 API Key。

### 二、安装和第一次打开

1. 从仓库的 Releases 页面取得 `MinisCanvas-<版本>-macos-universal.zip` 和同名的 `.sha256` 校验文件后，放在同一个文件夹里，在“终端”里运行 `shasum -a 256 -c` 加上校验文件名，确认输出 OK。
2. 双击 zip 解压，把 `MinisCanvas.app` 拖进“应用程序”文件夹。
3. 第一次打开可能被 macOS 拦下，因为安装包只做了“ad-hoc 签名”，没有经过 Apple 公证。按你的系统版本放行（以下步骤未在每个系统版本上逐一实测，如与你看到的界面不同，请以系统提示为准）：
   - macOS 14：在“应用程序”里右键（或按住 Control 点按）应用，选“打开”，在弹窗里再点“打开”。
   - macOS 15 及更新（含 26）：先双击打开一次（会被拦下），再到“系统设置 → 隐私与安全性”，往下找到“安全性”，点“仍要打开”，按提示确认（系统可能要你的登录密码）。这些系统上右键打开通常不再管用。
   - 也可以在终端运行：`xattr -dr com.apple.quarantine /Applications/MinisCanvas.app`。
4. 放行等于告诉系统“我信任这个应用”。请只放行来源可靠、校验和一致的安装包。自己从源码编译出来的应用没有这个拦截标记，通常不用放行。

### 三、配置服务商和 Key

Key 必须由你本人输入，不要让模型或别人代填，也不要把 Key 贴进聊天框。

1. 打开设置（菜单栏的设置项，或快捷键 ⌘,），进入“环境变量”页。这一页同时管理“模型供应商”和普通“环境变量”，供应商在上面那一栏。
2. 点“新增供应商”，会弹出“新增模型供应商”表单。你可以先点上面的预设（例如 DeepSeek、阿里云百炼），预设会帮你填好除 Key 以外的字段；也可以点“自定义”自己填：
   - 显示名：给自己看的名字。
   - 内部编号 / 凭据名：例如 `MY_PROVIDER_API_KEY`。
   - API Key：在这里输入你的 Key。
   - Base URL（可选）：例如 `https://api.openai.com/v1`。
   - URL 协议类型：OpenAI 兼容、OpenAI Responses、Anthropic、其他。
   - 模型名称：可手动添加多个，也可以点“获取模型列表”拉取，再点“应用目录”。“获取模型列表”只是查询，不会保存。
3. 点“保存”。应用会自动检查服务商是否就绪，不用再另外点检查。
4. 到“常规”页的“默认模型”一栏，选好“模型服务商”和“模型”，以后新建会话会自动用它。“辅助模型”留空则继承主模型。

API Key 保存在 macOS 钥匙串里，设置文件里只留名称等信息，不留 Key 的值。

### 四、发出第一条消息

1. 点侧栏的“新建会话”（或 ⌘N）。
2. 在输入框里写一句话，按 ⌘Return 或点发送。
3. 还没有配置服务商时，对话区会显示橙色的“演示模式”标记，这时的回复是本地模拟的，不是真实模型。配置好服务商后会自动切换成真实模型。
4. 想换模型，用输入区里的模型选择器。

### 五、认识主界面

- 左边是会话侧栏：新建会话、新建组、搜索、已置顶、已归档、授权项目目录。
- 中间是对话区和输入区。输入区里有权限模式、工作量、思考强度、模型、附件、插件或技能选择器。
- 右边是“上下文”面板，包含文件树、内置浏览器和终端，还能看到本回合的上下文来源、步骤清单、文件改动和压缩入口。
- 设置：⌘, 打开。快捷键、命令面板、斜杠命令见第 5 章。

## 1. 开始一次对话

### 新建会话和检查内容

1. 点“新建会话”或按 ⌘N，进入一个空会话。
2. 写一个简短的问题，发送。
3. 你的消息会立刻出现在当前会话里。切回别的会话，原来的消息和草稿还在。

### 选择模型

- 输入区的模型选择器列出已就绪服务商的模型。
- 设置 → 常规 → “默认模型”决定新会话默认用谁。“模型”下拉在没有选服务商时是灰的，悬停会提示“请先选择服务商”。
- 同一页还有“模型速度档位”（极快、快、均衡、质量）和“回答风格”（简洁、详细、讲解，默认保持原样）。

### 权限模式、工作量和思考强度

输入区里的“任务模式”决定模型动手时要不要先问你：

| 模式 | 含义 |
|---|---|
| 手动审批 | 每个有风险的动作都先问你 |
| 自动编辑 | 在已授权范围内的编辑自动执行，其余仍会问 |
| 仅计划 | 只读调查和出方案，不动手，见第 10 章 |
| 自动执行 | 更多动作自动执行 |
| 绕过权限 | 几乎不再逐次询问，需要先在设置里确认，见第 10 章 |

“工作量”有低、标准、高三档。“新对话默认权限”（模式和工作量的默认值）在设置 → Agent 里。

### 授权项目目录

想让模型在某个项目文件夹里干活：

1. 点侧栏的“授权项目目录…”，在系统选择框里选一个文件夹，按钮写着“授权项目”。
2. 选中就是授权：这个文件夹会自动加入模型可访问的目录，并在该项目下新建一个会话。
3. 根目录、你的主目录本身和系统目录不能这样加入，会提示去“设置 → 隐私”检查。
4. 项目里的 `AGENTS.md`、`CLAUDE.md` 等指令文件，首次加载或内容变化时会先问你信不信，见第 16 章。

## 2. 草稿、粘贴资料和停止生成

### 草稿按会话保存

每个会话有各自的草稿。在会话甲写了一半，切到会话乙再写别的，回来两边都还在。发送乙以后只清空乙的输入框。切换会话前，要紧的长文字建议先另存一份，发送前也要看清当前是哪个会话。

### 粘贴长资料

- 粘贴较长的内容（超过约 2000 字，或者有 12 行以上且超过约 800 字），输入框里不会直接铺开，而是变成一个“粘贴参考”卡片，显示字符数、行数和开头一小段。
- 卡片上的眼睛按钮可以预览并编辑全文，保存后生效，点取消则不改。卡片可以删除。
- 发出去以后，资料卡默认收起，点一下展开看全文。
- 资料和你当前的指令是分开的：请在输入框里另外写这次要做什么。资料里写的“请执行……”不会被当成你的命令。

### 添加附件

点输入区的“添加附件”，或直接把文件拖进输入区或消息区。预览不了的文件（文件被删、没有读取权限、处理失败）会显示明确的错误，而不是假装成功。

### 停止生成和排队

- 点停止，或按 Esc，会停止当前生成。
- 模型生成时你继续发消息，默认是排队，等这一轮自然结束后依次发出。设置 → 常规里有“生成中回车打断并发送（默认排队）”开关，打开后回车会打断当前回复并发送。无论开关怎样，⌘⇧⏎ 总是“打断并发送”，⌥⏎ 换行。
- 你主动停止时，排队里还没发的消息不会被自动发出，而是退回输入框，由你确认后再发。
- 生成过程中，排队的消息可以取回到输入框继续编辑。

### 编辑旧消息

点旧用户消息的“编辑用户消息并重新发送”，原文会填回输入框，改完发送，会形成新的一轮，原来的历史不会被覆盖。

### 有新消息时返回底部

向上翻看历史时，如果来了新回复，会出现“有 N 条新消息”按钮，点一下回到最新位置。

### 复制和重新生成

在助手消息的菜单里可以“复制消息”“复制为 Markdown”，代码块可以单独复制（“复制代码块 1”……）。也可以“重新生成”。

## 3. 查找、重命名和整理会话

- 搜索：在侧栏搜索框输入标题或正文关键词，点“清空消息搜索”恢复列表。
- 重命名：在输入框输入 `/rename` 后按提示填“会话名称”，或右键会话选择重命名。
- 分组：点“新建组”，填组名创建。会话可以放进组里；组可以重命名。
- 置顶：右键会话置顶，会出现在“已置顶”里；取消置顶后回到原来的组。
- 未读：右键会话可以标记未读，打开会话后标记消失。
- 归档：归档后会话从活动列表消失，到“已归档”里可以找回并继续使用。
- 复制：可以“复制全部对话内容”，也可以复制会话 ID 或深链。
- 导出：“导出会话为 Markdown”，默认只导出正文，可选带上安全的工具摘要。
- 删除：删除会话会先移入回收站，提示出现后几秒内可以点“撤销”。回收站在设置 → 存储里。要彻底删除，需要先核对会话名并完整输入，再输入“永久删除”，不可恢复。

## 4. 设置和界面布局

### 打开设置

按 ⌘,，或在菜单栏打开设置。设置分这些页：常规、安全、权限、项目、排版、快捷键、Agent、MCP、技能、定时任务、用量、隐私、存储、浏览器、记忆、环境变量、日志、关于。

### 常规页

- 外观：“主题预设”可选“产品主题”或“跟随系统”。
- 默认模型：服务商、模型、辅助模型。
- 语言：只管语音识别和朗读用的语言，不会切换界面语言，界面目前只有中文。
- 行为：模型速度档位、回答风格、“保留文件检查点”、“生成中回车打断并发送”、“启用对话人格”。
- “恢复全部默认设置”会清空自定义设置，点后有确认，取消或关闭都不会改变当前设置。它不会删除会话、服务商和凭据、记忆、MCP 配置和日志，也不会重置快捷键。

### 布局

- 左侧侧栏可以折叠，快捷键默认 ⌘⇧C；拖动分隔线调整宽度。
- 右侧上下文面板可以隐藏和显示，默认 ⌥⌘→，也可以调宽度。
- 窗口很窄时，建议先收右栏再收左栏，输入和发送仍可用。

### 日志

设置 → 日志可以选择日志级别，级别重启后保留。

### 关于

显示版本，有“复制版本信息”按钮和“许可证与第三方声明”。

## 5. 命令面板、斜杠命令和快捷键

### 命令面板

按 ⌘K 打开，输入关键字搜索命令，Esc 关闭，不会改动你的草稿。常用命令可以点旁边的星标收藏，收藏会出现在面板顶部，重启后还在。

### 斜杠命令

在输入框输入 `/` 会列出命令，继续输入可筛选，用上下键选择。命令不可用时会显示原因。常用的有：

| 命令 | 作用 |
|---|---|
| /help、/commands | 帮助和命令列表 |
| /status | 当前状态 |
| /goal | 设定或查看会话目标，见第 9 章 |
| /plan | 进入计划模式 |
| /compact | 压缩上下文，可以加一句关注点 |
| /context、/usage | 上下文和用量 |
| /tasks、/stop、/retry | 任务列表、停止、重试 |
| /rewind | 回退检查点 |
| /rename、/export、/resume | 重命名、导出、恢复会话 |
| /clear | 新会话 |
| /permissions、/mcp、/skills、/memory | 查看权限、MCP、技能、记忆范围 |
| /doctor | 环境诊断 |
| /shortcuts | 打开快捷键设置 |
| /approve、/reject | 批准或拒绝当前审批请求 |

输入框里写的斜杠命令按命令处理，不会当成聊天消息发给模型。有些命令会先走审批。

### 默认快捷键

| 快捷键 | 动作 |
|---|---|
| ⌘K | 命令面板 |
| ⌘N | 新建会话 |
| ⌘L | 聚焦输入框 |
| ⌘Return | 发送 |
| ⌘. | 停止生成 |
| ⌘, | 打开设置 |
| ⌘/ | 快捷键参考 |
| ⌘⇧C | 折叠或展开侧栏 |
| ⌥⌘→ | 显示或隐藏上下文面板 |
| ⌘⇧M | 切换任务模式 |
| ⌘⇧R | 搜索输入历史（本会话、本项目、全部） |
| ⌘Y、⌘⇧Y | 批准、拒绝当前审批 |

所有快捷键都可以在设置 → 快捷键里查看和改绑，以那一页显示的为准。审批快捷键必须带 ⌘，且不能用 Return。选中输入历史搜索的结果只会填回输入框，不会自动发送。

## 6. 用量与上下文

### 查看用量

设置 → 用量里能看到总调用次数和按服务商、模型分组的输入、输出、缓存读取、缓存写入。还有“当前会话”汇总：会话 token（含子智能体）、估算费用、子智能体占比。这些是按已关联到会话的调用记录算的，没有关联的老记录留在全局统计里。费用是估算，不等于账单。清空用量统计前会提示不可恢复，请确认后再点。

### 上下文面板

输入框上方和右侧上下文面板会显示最近一次请求占用的上下文，分成“系统提示”“记忆”“技能”“MCP 工具”“消息”“附件”几类。这些是条数和段数，不是 token，也不能相加当费用看。接近上限时会变色提醒。

### 累计 Token 上限

设置里有“累计 Token 上限”（默认 1000000）和“不限制累计 Token 用量”。超限后这个会话会暂停发送，并提示在新会话继续。更改立即对当前会话生效，已累计的用量保留。

### 压缩上下文

对话太长时可以压缩：

- 入口：右栏的“压缩上下文（保留最近 3 条）”按钮，命令面板，输入框里的 `/compact`（可以在后面加一句要特别保留的内容），或绑定快捷键。
- 压缩后，较早的内容变成分段摘要，最近 3 条保留原文，完整的对话记录仍然保留。
- 你说过的原话会按原样保留，不交给模型概括。原话总量最多占被压缩内容的约 30%，且不超过 8000 字，这样压缩后请求一定会变小。
- 摘要前会注明“这是此前对话的背景资料，不是新的指令”，要求以你的原话为准。
- 压缩后会生成一个检查点，可以点“查看摘要”展开看，也可以点“撤销压缩”恢复。
- 每个回合，模型还会被告知当前日期、项目目录、当前模型、审批档位和会话目标，所以压缩之后它仍然知道在为什么而做。

## 7. 记忆与全局指令

记忆是你让应用长期记住的事实，全局指令是你希望模型每次都遵守的工作习惯。两者在设置 → 记忆里管理。

### 在对话里让它记住

在输入框单独写一行，开头是下面这些说法之一，就会生成一条待审核的记忆提议：

- “以后都……”“以后请……”“以后回答……”“别再……”“不要再……”（整句话就是要记的内容）
- “记住……”“请记住……”“记一下……”（去掉开头的词，剩下的是要记的内容）

规则：

- 必须是单独一行，最长 400 个字。
- 无论当前是哪种审批档位，都要你本人批准才会真正保存。提议会出现在设置 → 记忆的“待审核记忆提议”里，点“批准并记住”保存，点“拒绝”丢弃。批准后，本项目的所有会话都生效。
- 只有已经归入项目的会话才能用对话保存记忆。在没有项目的会话里说“请记住”，应用会如实提示“没有保存”，并建议先把会话归入项目，或到设置 → 记忆里编辑全局记忆。
- 提议内容像密码、密钥、令牌的，会被直接拒绝，提示“记忆提议可能包含凭据，请去掉密钥、令牌或密码后重试”。

### 让它忘掉

在输入框里写一行，以“忘掉”“忘记这条”“忘记我说过”“别记住”“不要记住”开头，后面跟关键词。应用会直接打开设置 → 记忆页，搜索框已经预填好关键词，由你在结果里自己删除。这条话不会发给模型，也不会进对话记录。“忘记密码怎么办”这种普通提问不会被拦截。

### 每个回合带上哪些记忆

- 你的个人偏好、全局记忆，以及本项目已批准的记忆，每个回合都会带上。其余记忆按关键词匹配挑选。
- 带上的记忆总长度有上限（约 4000 字），放不下的靠后的会被略去。
- 记忆前面会提示模型“这些记忆可能已过时”，涉及具体文件、命令或数据时要先核实。
- 每条记忆带上了写入日期，格式类似“（记于 2026-11-15）”，方便模型判断是否过时。
- 设置 → 记忆页有“对话中使用已批准记忆”开关，关掉后这些记忆不再带入对话。

### 全局指令

- 设置 → 记忆页最上面是“对话中使用全局指令”开关，旁边是“编辑全局指令…”。全局指令对应的是文件式记忆里的 GLOBAL.md。
- 全局指令单独限 1200 字，不占用记忆的额度，也不受“对话中使用已批准记忆”开关影响。
- 超过 1200 字时，编辑窗口会提示“已超过 1200 字。保存会保留全文，新回合只使用前 1200 字。”
- 全局指令为空时，使用内置的默认版本。默认版本主要是工作习惯：先判断你是在提问还是下任务、信息够就直接做、结束时说明哪些已验证、不编造结果等。它明确写着“不能授予工具、文件或网络权限”。
- 编辑窗口里有“导入内置默认指令”按钮，把默认版本填进编辑框。这个按钮只在编辑框是空的时候可点。
- 在记忆列表里，全局指令的状态会显示“文件已加载”、读取失败，或“全局指令已关闭”。

### 记忆页的其他功能

- 手动新增：在“输入要记住的内容…”里写，选分类（用户偏好、安全、经验教训、一般事实），点“新增”。
- 搜索：用“检索当前作用域记忆…”。
- “清空全部”会先预览再确认。
- 导出 JSON 和导入 JSON 用于完整备份回导；导出 Markdown 和导入 Markdown 便于阅读和修改，导入前会预览，再选择个人、项目或临时范围确认。
- “记忆提议来源”里可以单独开关各个来源，内建来源默认开启，外部来源默认关闭，每条记忆仍须单独批准。
- 文件式记忆区列出 GLOBAL.md、SOUL.md 和每日日志，可以打开查看、编辑、删除。

## 8. 技能

技能是一份写好的“做法说明”（一个 SKILL.md 文件），模型遇到相关任务时会按它做。技能默认不启用，必须经过你审核批准。

### 查看和导入

设置 → 技能页：

- “导入本地技能…”：选一个含 SKILL.md 的文件夹，会进入审核窗口。
- “导入内置技能…”：展开“内置技能库”，列出 9 个内置做法技能。点名字查看全文，进入同一个审核窗口，你明确批准后才会启用。
- “技能目录”：用“添加技能目录…”和“添加项目目录…”让应用扫描某个目录（项目目录扫描其中的 .claude/skills）。扫到的技能仍需导入、审核、批准才能启用。
- 每个技能有开关、版本和来源，可以“更新技能…”“移入回收站”“回滚上一版本”，被删除的技能可以在“技能回收站”里恢复。

### 审核窗口

标题是“审核本地技能”，会显示名称、版本、来源路径、内容的 SHA-256、适用范围（当前会话和项目，其他会话或项目需要重新审核）和前 2048 个字符的预览。点“明确批准并启用”才会生效，“暂不批准”则什么也不做。内容变了，旧的批准就不再有效，需要重新审核。

### 9 个内置技能

界面里显示的是下面的英文名，括号里是一句话用途：

| 技能名 | 用途 |
|---|---|
| planning-playbook | 拆解多步骤工作（规划） |
| code-change-playbook | 实现或修复代码（改代码） |
| debugging-playbook | 定位可复现故障（排查） |
| research-verify | 核查资料与说法（调研核实） |
| writing-summary | 起草或压缩文字（写作总结） |
| app-settings-change | 核对或调整应用设置（改设置） |
| subagent-dispatch | 协调可独立的委派（派子任务） |
| goal-long-task | 维护长任务验收状态（长任务与目标） |
| cross-session-relay | 整理跨会话交接 |

### 模型怎么用技能

- 每个回合，模型都会看到可用技能的目录（名称和一句话用途）。
- 与当前任务相关的技能，正文会另外附上。每个回合最多带 3 个技能、合计约 3000 字。
- 本会话里命中过的技能，之后的回合会继续带上，最多 2 个；如果技能内容改了，或者适用范围变了，就不再自动带。

### 在输入框里选技能

输入区的“选择插件或技能”按钮可以查看可用条目，Esc 关闭。

## 9. 目标与长任务

对一件要做很多轮的事，可以给会话设一个“目标”。应用会记着目标，在每一轮结束后按设置自动续跑，直到模型提交完成证据并通过核对。

### 设定和查看

- 输入 `/goal 你的目标`（要在输入框里单独输入这条命令）设定目标。点发送按钮和按回车效果一样。
- 单独输入 `/goal` 不带内容，会显示当前目标；没有目标时提示你怎么设定。
- 输入区上方的目标栏也有“设定目标”按钮，填好后点“开始”。
- 计划模式（仅计划）下不能自动续跑，其他模式可以。

### 目标栏上的按钮

- 状态标签：进行中、正在核对完成证据、受阻、已暂停、已停止、已完成。
- “预算”：设回合上限、Token 上限、时长上限（分钟），Token 和时长可以填“不限”。
- “开启自动续跑 / 关闭自动续跑”：自动续跑是每个回合正常结束后继续下一轮。
- “暂停”“恢复”“停止”。预算用完以后要先调高预算，再点恢复。
- 目标栏下面显示目标回合数、Token、时长的使用情况，以及会话累计 Token。

### 什么时候会自动暂停

续跑回合里模型一个工具都没调用（空回合）、你拒绝了续跑回合里的一项操作、回合被停止或没能结算、会话累计 Token 到上限、预算用尽，都会暂停并说明原因。

### 完成与核对

模型认为目标完成时，会提交完成证据，应用另行核对。可以看到“上次复核”的结论：复核通过、复核未通过、复核超时等。未通过时可以回复一句，让模型补充证据后重新提交。“完成证据”可以展开查看。

### 待你处理

如果模型被卡住，需要你做决定，目标栏会出现“待你处理（N）”，展开能看到原因、需要你做什么和可选项，选好后直接在输入框回复即可。

### 其他相关

- 目标会写进每回合的环境信息里，压缩之后模型仍然知道目标。
- 用户中断之后，下一回合模型会被提醒先说明哪些结果已经确认、哪些还需要核实。
- 内置技能 goal-long-task 描述了长任务该怎么维护验收状态，可以按第 8 章导入。

## 10. 工具审批与权限模式

### 审批卡怎么看

默认的“每次询问”档下，不是所有动作都弹卡：在你授权的目录内，读文件、搜索、压缩上下文、向你提问和读取技能不会弹审批卡；敏感文件、写文件、编辑、删除、执行命令、网页抓取和对外发送，仍然照常审批。“绕过权限”档几乎不再逐次询问，但有硬安全边界（见下文）。

需要审批时会弹审批卡，显示工具名、脱敏后的输入摘要和风险等级。读取类动作会显示读取目标的完整路径。请先看清楚，再点：

- “允许”（或“拒绝”）。中、低风险按 Return 可以允许；高风险不会用 Return 一步放行。
- 高风险操作需要第二次确认，点“我了解风险，仍然允许”才会执行。
- “本对话内都允许”：本会话内同类操作不再询问（限时）。
- 部分操作提供“以后都允许……”，会保存成持久规则，只对本项目和当前配置生效。所有规则可以在设置里的“已允许的规则”看到并撤销。有些命令不提供“以后都允许”，卡片会写明原因。
- 快捷键默认 ⌘Y 允许、⌘⇧Y 拒绝，也可以用 `/approve`、`/reject`。
- 如果审批过期，或者目标在你审批前发生了变化，旧的“允许”会失效，需要重新审批，不会沿用到新目标上。

### 文件改动预览

删除、覆盖写入、编辑文件时，审批卡会给出预览：删除显示完整路径、大小和前几行；覆盖写入显示大小和行数变化；编辑显示 diff，可以点“展开预览”看更多。敏感文件（比如 .env）只显示名称、大小和提示，不显示内容。

### 授权目录

设置 → 权限页可以“添加本会话目录”或“添加本项目目录”。会话授权只对当前会话有效，项目授权同项目的其他会话也能用，可以撤销。设置 → 隐私页的“挂载文件夹”最多同时挂 10 个，被拒绝的目录即使在根目录里也会被拦截，默认拒绝包含应用自己的数据目录。

### 计划模式（仅计划）

选“仅计划”后，模型只做只读调查，有副作用的动作只预演。

- 需要向你澄清时，模型会用“澄清问题”卡片提问，你选择选项、点“其他…”写自己的回答，再点“提交回答”或“取消澄清”。选项只作为回答交回模型，不会被当成要执行的命令，卡片默认一直等你，切换会话不会自动继续。
- 模型的最后一条回复就是计划，下面会出现计划卡，有“批准并自动编辑”“批准并逐项审批”“继续规划”三个选项。批准后应用会切换到相应模式，并开始执行。

### 绕过权限模式

要用得很谨慎。

- 需要先到设置 → Agent，勾选“我同意绕过权限：可读写删除电脑上任意文件、执行任意命令（系统文件与已安装软件除外）”并保存。共用的电脑可以勾选“禁用绕过权限模式”。
- 默认还会保护凭据类路径（~/.ssh、~/.aws、~/.gnupg、.env、密钥文件、钥匙串命令），请保持开启。
- 绕过档有硬安全边界：不能改动操作系统的系统文件、不能卸载已安装的软件，并保护应用自己的数据目录与钥匙串。绕过档下浏览器的点击、输入、下载、上传也不再逐项弹卡；只有"向外部智能体会话发送消息"仍然每次询问。
- 只有在你完全信任当前任务和模型时才使用，并事先备份重要数据。

### 运行安全

设置 → 安全页有“停用所有工具”，和一个离线开关：关闭画布、MCP、外部智能体等可选副作用，聊天、备份和恢复仍可用。

## 11. 文件、检查点与备份

### 检查点

设置 → 常规 → “保留文件检查点”打开后，模型改文件之前会先保留原来的样子。

- 在停止生成后，选一个检查点点“恢复文件和对话”，文件、对应的消息和步骤进度会一起回到那一刻。
- “会话锚点 · 仅回退会话”只回退对话，不恢复文件，最后确认时会写明不可撤销。
- 检查点保留 30 天，过期后不能恢复。命令行（shell）造成的改动不在检查点范围内。
- 命令 `/rewind` 打开回退入口。

### 查看本回合的文件改动

右栏的“文件改动”可以按文件展开 diff，切换不同回合，也可以对某一行写评论，评论会作为新消息交给模型。

### 查看产物

在“变更文件”里找到模型新建或写入的文件，可以预览、用系统打开、在 Finder 显示或复制路径。文件已被删除、没有权限时会给出明确的提示。

### 备份和恢复（设置 → 存储）

- “导出备份”：生成 `.minissync` 文件，包含会话、长期记忆、技能和设置四类数据，不包含钥匙串里的 Key，也不包含画布和文档阶段数据。导出时可以勾选“使用密码保护导出”；不勾选则明文保存，里面是你的私人会话和记忆，请妥善保管。密码要由你自己输入。
- “导入备份”：先“只读预演”，列出来源、版本、各类数据的数量和冲突，再逐类选择。点“确认范围并导入”并勾选“我已核对恢复范围，并知悉完成后必须重新打开应用”后，应用会先自动做一份完整备份，再导入。失败会恢复原来的文件，导入成功后要重新打开应用。
- 备份里的浏览器写入和子任务自动删除审查，导入后会被强制关闭，需要你自己重新开启；凭据不会恢复。
- 这一页还有“回收站”“保留策略”（提醒清理过期会话，不会自动删除）、“清空全部会话”和“清空全部记忆”（都会先确认）。

### 数据放在哪里

数据都在你的电脑上：`~/Library/Application Support/MinisCanvas/`（会话、日志、后台命令记录）和 `~/Library/Application Support/MinisCore/`（设置、环境变量元数据、MCP 配置、技能）。API Key 放在钥匙串里。

## 12. 终端与后台命令

### 在右栏终端或对话里运行命令

右栏有终端面板。让模型运行命令时，它会在你授权的目录里执行：

- 先核对审批卡里的目录和命令，再决定允许。
- 完成后会显示输出和退出码。“完成”不代表退出码是 0，请看退出码。
- 命令里的密钥类变量默认会被剥离，命令环境默认是“非交互”的，这两项在设置 → Agent 的“命令环境”里。

### 终端命令策略

设置 → Agent → “终端命令策略”分三类：自动允许、每次确认、用户追加拒绝，可以搜索和调整。系统硬拒绝的命令只读，不能移除；硬拒绝的命令在审批卡里只有“拒绝”，没有“允许”。点“恢复终端规则默认值”需要确认。

### 后台命令

长时间运行的命令可以放到后台，之后让模型读取输出或停止。后台命令属于当前会话，别的会话不能操作它。

### 绕过模式的底线

即使在绕过权限模式下，仍有两条底线：不能改动操作系统的系统文件，不能卸载已安装的软件。命令的识别是尽力而为，不能当作完整的安全沙箱，请不要把它当成保护你的唯一一层。

## 13. 子任务与任务中心

### 子任务

模型可以把相对独立的工作交给子任务并行处理。你可以：

- 在对话里要求“请把 A、B 两件事分别交给子任务做”。
- 在审批卡上核对子任务的目标目录和可用工具，子任务只能用它自己被声明的范围，不会因为父会话能读就都能读。
- 通过“把子任务转入后台运行”让父会话继续。后台完成后，结果会在你的下一轮消息里带回一次。
- 点“查看子任务”可以只读查看子会话的输入、脱敏后的结果和完成状态，然后返回。

设置 → Agent 里有相关开关：“允许子任务写入、编辑、删除文件及执行命令”（默认开启，仅影响新回合，仍遵循父会话的权限和审批）、“允许子任务使用其他模型和思考档位”、“自动审查子任务的文件删除（默认关闭）”。

### 任务中心

任务中心列出当前任务和折叠的最近历史，可以：

- 展开某个任务查看来源、最近步骤、耗时和失败原因；
- 暂停、恢复、重试失败的任务（重试同样要审批）；
- 点“停止全部后台子任务”并确认，可以一次取消所有后台子任务；
- 按进行中、待审批、失败、完成筛选，以及归档和恢复归档。

关闭任务中心可以用顶部关闭按钮、Esc 或 ⌘W。

## 14. 外部智能体

除了应用自带的模型，MinisCanvas 还能调用你电脑上已经安装的命令行智能体，例如 claude、codex（另外也识别 hermes），把一件事交给它们完成，再把结果带回对话。

### 怎么用

1. 先在电脑上自行安装并登录好这些命令行工具。MinisCanvas 不负责安装，也不保存它们的登录信息。
2. 在对话里说明要交给谁，例如“请把这件事交给 claude 去做”。模型会发起一次调用。
3. 会弹出审批卡，标题类似“启动外部程序：claude”，并写着警告：外部程序以你的用户身份在本机运行，可以读写你有权限访问的文件，不受本应用的文件范围、Hooks 和审批约束。这是高风险操作，请看清后再批准。

### 去哪里找程序

应用依次到这些常见位置找：claude 在 `~/.local/bin/claude`、`/opt/homebrew/bin/claude`、`/usr/local/bin/claude`；codex 在 `/opt/homebrew/bin/codex`、`~/.local/bin/codex`、`/usr/local/bin/codex`；找不到时再查系统路径。如果还是没找到，错误提示会列出已经找过的所有位置，你对照着确认安装路径即可。

### 在哪个目录运行

外部程序在当前授权的项目目录里运行。如果会话没有项目目录，或目录是根目录、你的主目录，就改在一个新建的临时目录里运行，避免它碰到不该碰的地方。

### 读取外部会话

设置 → 隐私里有“允许读取本机 Codex / Claude Code 会话”开关：只读、内容脱敏，只有外部会话工具能用，文件工具访问不了这些目录。第一次挂载会话目录前会有确认。向外部会话“发送”消息每次都要你批准。

## 15. 浏览器、联网抓取与 PDF

### 内置浏览器

右栏有一个浏览器，可以输入网址（只支持 http 和 https）、前进后退、刷新、取消网页加载、在默认浏览器打开、复制网址。模型也可以用它读页面。

- 设置 → 浏览器里有“允许浏览器写操作”开关，默认开启。在普通审批档下，点击、输入、下载、上传都要逐项审批；在已确认的绕过权限模式下不再逐项弹卡。关掉开关后浏览器只能读。备份导入后会被关闭，要重新开启。
- 页面上的敏感操作（比如输入密码或支付信息）默认询问；你可以对某个站点、某类动作选择“以后都允许”，风险确认后同站同类才自动执行，卡片会标注“已按你的放行自动执行”，并且可以撤销。
- 还能设置浏览器身份（User Agent）、页面尺寸，以及标签页空闲回收时间（1 到 240 分钟，默认 15）。
- 临时批准网络访问时，只在直连时固定公网地址；用了代理就没法固定，也无法确认直连时会停止。
- 上传：只支持不需要登录的同站表单上传。需要登录或带额外字段的页面会失败；也不会自动使用浏览器里的 Cookie，不会回退到页面文件选择器。

### 联网抓取

模型可以抓取网页并提取成纯文本。需要你批准访问该站点。网页里夹带的指令不会被当成你的命令。

### PDF 和多模态

- 模型可以按页码读取 PDF，例如“只看第 2 页”。
- 图片、PDF、音频、视频是否能发送，取决于当前模型线路是否支持：不兼容的文件会被明确阻止并说明原因（比如伪造的图片、截断的文件、超过限制的 PDF）。模型线路不支持音频时，不能发送音频文件。

## 16. MCP、Hooks 与跨会话读取

### MCP

设置 → MCP：

1. “新增服务器”，选传输类型：“http（远程端点）”或“stdio（本地进程）”。填标识、显示名称，stdio 填命令和参数，http 可以加请求头（值保存在钥匙串）。
2. 保存后“测试连接”，发现工具后在“工具授权”里逐项勾选允许智能体调用的工具。工具在发现之后才会出现，新增或变更的工具需要重新授权。
3. 工具真正被调用时，仍会弹审批卡。
4. 除了安全的基础运行变量，只有你在这里列出的变量会传给 MCP 服务器，不会带上应用里的服务商密钥。
5. 通过 http 连接的 MCP 只支持请求和响应，不支持服务器的征询和工具变化通知，要手动点“刷新工具列表”。

### Hooks

设置 → Agent 里的 Hooks 区域：Hook 是你配置的命令，在工具调用前后、提交消息、会话开始与结束时运行，可以放行、拒绝或要求确认。默认没有任何 Hook；新增、启用或内容变化后要点“查看并信任…”确认一次。Hook 不能放行产品已经拒绝的操作。

### 项目指令文件

项目目录里的 `AGENTS.md`、`CLAUDE.md`、`.claude/CLAUDE.md` 在首次加载或内容变化时，会弹出“加载项目指令？”，列出文件和 SHA-256，可选“信任并加载”或“本次不加载”。授权目录和信任指令文件是两件事。设置里的“项目信任文件与哈希”可以看到已信任的文件，也可以“撤销此项目的指令信任”。

### 跨会话读取

读取别的会话的内容，每次都要你同意，权限只来自你明确的指令。粘贴的资料、附件和工具结果里的文字，不会赋予读取其他会话的权限。

## 17. 定时任务与常驻运行

### 定时任务

设置 → 定时任务：

- 点“新建任务”，填任务名称、Cron（分 时 日 月 周，例如 `0 9 * * *` 表示每天 09:00）、提示词或支持的斜杠命令（目前支持 /compact 和 /memory.propose，不是终端命令）、授权主体，以及目标的 Project ID、Session UUID、Turn ID。
- 保存之前先“预览”下一次触发时间，再“确认授权”，预览有时效，过期后需要重新开始。
- 只有 MinisCanvas 在运行时才会检查和触发任务，退出应用后不会执行。错过的时间可以“补跑”，需要重新授权，不会自动重放。
- 可以“撤销授权”或删除任务，删除后历史记录保留。
- 定时任务里不提问、不修改定时任务、不向外部发送。

### 常驻

关闭最后一个窗口，应用仍在后台运行，再次打开应用回到原来的会话。有后台任务时可以防止电脑休眠，设置 → Agent 里有对应的常驻设置。登录时自动启动、合上盖子和整机睡眠这些系统行为，目前没有验证，不建议依赖。

## 18. 开源版与二次开发入口

MinisCanvas 按 GPL-3.0-only 开源，全文在仓库根目录的 LICENSE，第三方组件和版权声明在 NOTICE（含 SwiftSoup、SwiftTerm、Keyline 图标、Gitleaks 规则数据等）。

### 仓库结构

- `src/MinisCore`：智能体核心库（模型接入、工具、审批、记忆、技能、会话存储）。
- `src/MinisCanvasApp`：主应用，界面和各设置页都在这里的 `Sources/MinisCanvasApp/` 里。
- `src/CanvasCore`：画布核心库，主应用依赖它；画布功能目前冻结。
- `src/CanvasApp`、`src/MinisApp`：旧的独立入口，不保证可用。
- `scripts/`：构建、测试、打包脚本。

### 自己编译与测试

需要 macOS 14 以上和 Xcode（已验证 Xcode 26 / Swift 6.3.3）。构建、打包、测试的完整说明见 [BUILDING.md](../BUILDING.md)；公开测试入口是 `scripts/test_core.sh`（覆盖 MinisCore 与 CanvasCore）。主应用的部分测试需要原生宿主和“辅助功能”授权，普通 `swift test` 不保证全绿。

### 想改界面文字或行为

界面文字大多写在 `src/MinisCanvasApp/Sources/MinisCanvasApp/` 下对应页面的 Swift 文件里；对话相关逻辑在 `ChatStore.swift`；记忆注入在 `src/MinisCore/Sources/MinisCore/Memory/MemoryInjector.swift`；内置技能文本在 `DefaultPromptSkills.swift`。

### 提醒

智能体工具能读写文件、执行命令、访问网络，二次开发或自行使用时请先理解审批机制，并对重要数据自行备份。产品内含一些内部验收用代码和环境变量（如 `MINISCANVAS_FIELD_PROFILE`），默认不启用。

## 19. 常见问题

**打开时提示“已损坏”或“无法验证开发者”怎么办？**
先核对校验和。校验通过且来源可靠，再按“快速开始”里的放行步骤处理。

**我没有配置服务商就发消息，回复是什么？**
会显示“演示模式”，回复是本地模拟的，配置好服务商后自动切换。

**发出去的消息一直没有回复？**
先看服务商和模型是否就绪、网络是否通；也可以输入 `/doctor` 看环境诊断，或在菜单“命令 → 导出脱敏诊断包…”导出诊断包，附在 issue 里，里面的敏感内容会被遮蔽。

**请求失败的提示里有哪些分类？**
配置失败、401 和 403（认证）、404、429（限流）、5xx（服务端）、超时、取消。遇到限流会自动等待重试，你也可以点“立即重试”，取消或按 Esc 会停止重试。多次重试用尽后，会出现专属处理卡，可以打开模型选择器换模型，或点“稍后”。

**我说“记住……”，为什么没有生效？**
记忆需要你在设置 → 记忆里批准；并且会话要先归入项目，否则会提示没有保存。见第 7 章。

**模型总是忽略我的偏好？**
检查设置 → 记忆里“对话中使用已批准记忆”和“对话中使用全局指令”是否开启；个别偏好请写成单独一行的“以后都……”让它生成记忆提议。

**怎么让它忘掉一件事？**
对它说“忘掉……”，应用会打开记忆页并搜索，你自己点删除。

**技能为什么没有生效？**
技能默认不启用，扫描到不等于信任。请在设置 → 技能里导入并审核，批准后才启用，而且适用范围是当前会话和项目。

**应用要访问钥匙串、文件夹、麦克风，是正常的吗？**
API Key 存在钥匙串里；文件夹访问由你授权的目录和审批控制；麦克风和语音识别只在你用语音输入时请求。

**为什么需要联网？**
应用本身不带模型，对话内容会发给你配置的模型服务商。网页抓取和浏览器会访问你让它访问的站点。设置 → 隐私里“匿名使用统计”和“环境变量值脱敏设置”开关都标着“尚未启用”。

**怎么卸载？**
退出应用，把它拖进废纸篓。想清除数据，先用“导出备份”备份，再删除两个 Application Support 目录（见第 11 章）；想清除钥匙串里的 Key，到“钥匙串访问”搜索 `com.miniscanvas.miniscore.envvars`；用过子任务独立工作目录的，还要检查 `~/.minis-worktrees/`，删除前确认里面没有未提交的工作。

## 20. 已知限制

- ad-hoc 签名、未公证的安装包在其他 Mac 上首次打开需要手动放行（见“快速开始”）；放行步骤在不同 macOS 版本上的实际表现未逐一实测。
- 通用包含 Intel 架构，但 Intel 机器上的实际运行尚未实机验证。
- 浏览器的上传只支持不需要登录的同站表单；需要登录或带额外字段的页面会失败，也不会自动使用浏览器的 Cookie。重新启动应用后，浏览器的地址栏为空，旧页面不会恢复。
- 通过 http 连接的 MCP 服务器不支持服务器征询和工具变化通知，需要手动刷新工具列表。
- 界面目前只有中文，设置里的“语言”只影响语音识别和朗读。
- “匿名使用统计”“环境变量值脱敏设置”两个开关尚未启用。
- 备份导入完成后必须重新打开应用；备份不含钥匙串里的 Key。
- 定时任务只在应用运行时触发；登录启动、合盖和整机睡眠等系统行为没有验证。
- 命令的危险识别是尽力而为，不是完整沙箱。绕过权限模式下只保证不动系统文件和不卸载软件这两条底线。
- 用量里的费用是估算，不等于服务商的账单。
- 很长的对话或超大的输出，可能出现卡顿。
- 画布功能冻结，本版本不开放。
- 外部智能体、MCP 和 Hooks 都是在你的电脑上运行外部程序，风险由你承担，请只信任来源可靠的程序。
- 本应用是早期版本（0.1.0），可能有缺陷，按 GPL-3.0-only 提供，不附带担保。本项目与 Anthropic、OpenAI 等公司没有从属或背书关系。
